# Fantasy NBA League Analyzer

A personal, non-commercial Yahoo Fantasy Basketball analytics project.

## Purpose
Analyze my private 13-team Yahoo Fantasy Basketball league.

## Features
- Compare team strengths across 11 scoring categories
- Analyze historical matchups and standings
- Evaluate player trades
- Optimize daily roster positions

## Data Access
Uses the Yahoo Fantasy Sports API with read-only OAuth authorization.

## Usage
Personal use only. No automated trades or roster modifications.
